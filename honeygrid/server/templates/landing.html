Plant

Six decoys, one line.

Each decoy is generated in the console and carries its own tripwire. Plant them where an attacker goes looking for secrets.

  1. Canary URLLinks in wikis, tickets and internal docs that record whoever follows them.
  2. PDF beaconA document that reports back when it is opened in a reader.
  3. AWS IAM keysA convincing ~/.aws/credentials file for infostealers and insiders.
  4. .env secretsDatabase and API credentials dropped into projects and backups.
  5. Git repositoryA decoy repo whose remote trips on git fetch or git pull.
  6. KeePass vaultA passwords.kdbx on a desktop or share that alerts when inspected.
Trip

Nothing legitimate touches a decoy.

Detection that watches real traffic has to guess what is malicious. A decoy has no legitimate users, so there is no baseline to tune and no threshold to calibrate: the moment one is opened, tried or followed, the trip itself is the signal. It arrives identified, and containment sits beside the evidence that justifies it.

What every hit carries

Location comes from the hosting edge first, with fallbacks through several geolocation services down to a country centroid. When a browser opens the trap, a silent probe adds hardware detail.

Network

  • Client IP behind trusted proxies
  • ISP and ASN
  • Tor exit, VPN, datacenter
  • Threat score 0–100

Place

  • City, region, country
  • Coordinates from edge headers
  • Plotted on the attack map

Device

  • GPU renderer
  • Screen, cores, memory
  • LAN address via WebRTC
  • Timezone and platform

Intent

  • Client tool from user agent
  • Method, path, headers
  • MITRE ATT&CK technique
Contain

Contain in one decision.

Alerts reach the team where it already talks, and containment sits beside the evidence.

  1. ADiscord SOC alerts

    Rich embeds with address, threat level, connection type, ISP and ASN, sent the moment a decoy trips.

  2. IIsolate the address

    One action writes a Windows Firewall inbound block rule on the sensor host.

  3. SOperator safe list

    Allowlist your own workstation so tests score zero and can never be isolated by mistake.
